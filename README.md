# fortshell
a simple and fast shell

# why use fortshell
if your device is low end 
and you want a shell thats soo simple and fast
that you can compile in 3 seconds and then edit
again and compile , then fortshell is a simple **choice**

# key features
*extremely lightwheight. fast on old systems*
*supports cd command*
*some custom commands*
*shell dosent terminate, if the user presses ctrl + c*
